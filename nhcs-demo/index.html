Relógio simulado

O Início muda com a fase da viagem. Adianta aqui o relógio para ver as quatro — é a mesma função que a app usa, com outra data.

Interface em português. O ecrã dentro da moldura corre o mesmo código da app em React Native — o mock, as fases da viagem e as regras do concierge são os ficheiros do projecto, com os tipos retirados para o browser os poder ler. A camada de desenho é que é reescrita, porque React Native não desenha em HTML.
